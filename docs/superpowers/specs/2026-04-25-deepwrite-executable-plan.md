## 执行模型

每个阶段内的任务按**依赖关系**组织为多个**波次（Wave）**，同一波次内的任务可**并行执行**。

```
Wave N → Wave N+1 → Wave N+2
  ↓         ↓         ↓
并行任务   并行任务   并行任务
```

### 任务卡片格式

| 字段 | 说明 |
|------|------|
| **任务ID** | P{阶段}-{序号}，如 P1-001 |
| **任务名称** | 具体可执行的工作项 |
| **负责人** | 角色分工 |
| **依赖** | 前置任务ID |
| **工时** | 预估小时数 |
| **成功标准** | 可验证的完成条件 |
